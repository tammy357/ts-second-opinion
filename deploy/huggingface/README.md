# TS Second Opinion (live demo)

The marimo demo from [github.com/tammy357/ts-second-opinion](https://github.com/tammy357/ts-second-opinion): browse the
LLM-written rules, triage any of 1,194 RDB7 reactions with GoFlow's guesses, view the TS in 3D and download an ORCA input.
Writing new rules needs Claude, so that button is disabled here; run the repository locally for it.
