Where should the DFT go?

You have machine-learned transition-state guesses for many reactions and DFT time for only a few. Set the number of runs you can afford and see which reactions to run, which to trust, which to hold back and which to re-generate. The plan is a fixed rule, not an AI judgement: the same reactions and budget always give the same plan.

Make it with tsso batch my_reactions/. The file is read in this browser tab and goes nowhere. Only ids, verdicts and disagreement values are used, no structures.

Ask about this plan

Ask Claude in your own words (needs your own Anthropic API key)
  • Claude cannot choose the reactions. It can only call the same fixed rule you see above, for this batch, and read the benchmark results.
  • It is sent ids, verdicts and disagreement values. It is never sent structures, and never the reference answers.
  • It is told to point at tool results instead of typing numbers; this page copies the values in and lists any number Claude typed itself.
  • Your key stays in this tab and is sent only to api.anthropic.com. Claude can be wrong; the plan above is the record.

What it cannot do

    Sending machine-learned TS guesses to DFT by a confidence score is not new (OA-ReactDiff, 2023), and neither are committee disagreement, random audits or bond checks on reaction paths. What we did not find elsewhere: a budget plan that works on any generator's guesses after the fact, an exact error bound from a random audit inside the same budget, and a reaction-path check that also compares handedness. Full results, limits and prior work.
